pub fn detect() -> Level
Expand description

The level a dispatch should run.

The higher of what the build proves and what the CPU has: a token where the CPU has more than the build, Level::Native where the build already has it all. With the portable feature, on soft-float targets (kernels), and under Miri without the features in the build, Level::Portable.

The CPU is asked once a process and the answer cached, as std::is_x86_feature_detected! caches it: every CPU the process runs on is taken to have the same features, which x86 operating systems and firmware keep true.
