Expand description

A set of CPU features, as a zero-sized value that proves the CPU has them. Sealed: the levels are hakmem’s.

The per-width methods are the hooks Word routes through; the generic ones (pext, select, …) are what code reads.

Required Associated Types§

Source

type U8x16: Lanes<Isa = Self, Bitmask = u16>

Sixteen byte lanes with this token’s instructions: a PSHUFB register on x86 with SSSE3, NEON on aarch64, two SWAR words elsewhere.
