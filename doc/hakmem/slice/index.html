Module slice 

Source
Expand description

Bit-set operations over a slice of words: the index-free layer between single-word combinators and a real succinct structure.

Every function is a linear scan over words with O(1) work per word; positions are absolute bit indices (word_index * BITS + bit). Build rank/select directories on top when the slice is large; use these directly when it is not, or when the words change often.

popcount
Number of set bits in the whole slice.

Number of set bits at positions < i. i may equal the slice’s bit length; larger i counts everything.
select
Position of the k-th set bit (0-indexed), if k < popcount.
