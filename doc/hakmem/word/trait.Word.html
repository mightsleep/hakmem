Expand description

A fixed-width word of BITS bits, bit 0 least significant.

Shift amounts passed to shl / shr must be < BITS; combinators in this crate uphold that by construction and debug-assert it.

Source

fn pdep(self, mask: Self) -> Self

Parallel bit deposit (PDEP): scatters the low count_ones(mask) bits of self to the set positions of mask, preserving order.

Source

fn select_lowest(self, k: u32) -> u32

Position of the k-th set bit. Precondition k < popcount; the result is unspecified otherwise. BMI2: trailing_zeros(pdep(1 << k, self)); portable: Vigna’s broadword select.

Source

fn xor_scan(self) -> Self

Prefix XOR: bit i of the result is the parity of bits 0..=i. PCLMULQDQ: carry-less multiply by all-ones; portable: log-depth smear.

Source

fn low_ones(n: u32) -> Self

Mask with the n lowest bits set, n <= BITS.
