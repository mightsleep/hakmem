Struct Affine8 

Source 
pub struct Affine8 { /* private fields */ }
Expand description

An affine map on the bits of a byte: x ↦ A·x ⊕ b over GF(2).

Every constructor is const; a map built from constants is a constant, and so are the tables tables derives from it.

Source

pub const fn sra(n: u32) -> Self

x ↦ (x as i8) >> n, arithmetic: shr with the rows of the vacated bits set to 0x80, the sign. n >= 8 fills every bit with the sign.

Source

pub const fn rotl(n: u32) -> Self

x ↦ x.rotate_left(n mod 8): the rows of shl and of shr by the complement, disjoint, combined.

Source

pub const fn rotr(n: u32) -> Self

x ↦ x.rotate_right(n mod 8).

Source

pub const fn apply(self, x: u8) -> u8

The map applied to one byte: eight ANDs, eight parities.

Source

pub const fn apply8(self, bytes: u64) -> u64

The map applied to every byte of a word at once: for each output bit, AND the word with the row splatted, fold the parity of each byte into its bit 0 with three XOR-shifts, and place it. Eight rounds of seven operations, no table; the SWAR carrier’s path.

Source

pub const fn tables(self) -> ([u8; 16], [u8; 16])

The nibble tables that compute the map by linearity: with (lo, hi) = m.tables(), m.apply(x) == lo[x & 15] ^ hi[x >> 4]. The constant lives in lo. This is what Lanes::affine runs through two lut16 where there is no GFNI.

Source

pub const fn then(self, next: Self) -> Self

self first, then next: the composite x ↦ next(self(x)). Its matrix is the product A_next · A_self, row i being the XOR of the rows of self selected by row i of next; its constant is next applied to self’s.

Source

pub const fn compose(self, first: Self) -> Self

self ∘ first: first is applied first. The same map as first.then(self), in the order mathematicians write it.
